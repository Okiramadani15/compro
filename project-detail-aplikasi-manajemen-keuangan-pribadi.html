DompetKu - Aplikasi Manajemen Keuangan Pribadi (Single User)

Deskripsi Project

DompetKu adalah aplikasi manajemen keuangan pribadi yang dirancang untuk membantu pengguna mengelola dan melacak keuangan mereka secara efektif. Aplikasi ini menyediakan solusi lengkap untuk pencatatan pemasukan dan pengeluaran, pengelolaan anggaran, serta visualisasi data keuangan.

Dengan antarmuka yang sederhana dan mudah digunakan, DompetKu memungkinkan pengguna untuk memantau kesehatan keuangan mereka, mengatur tujuan keuangan, dan membuat keputusan finansial yang lebih baik berdasarkan data yang akurat.

Fitur Utama

  • Pencatatan pemasukan dan pengeluaran dengan kategori yang dapat disesuaikan
  • Dashboard interaktif dengan ringkasan keuangan
  • Visualisasi data melalui grafik dan diagram
  • Pengelolaan anggaran bulanan
  • Laporan keuangan yang dapat diekspor
  • Pengingat pembayaran tagihan
  • Pelacakan tujuan tabungan
  • Enkripsi data untuk keamanan informasi keuangan

Teknologi yang Digunakan

  • PHP 8.0 dan MySQL untuk backend
  • Bootstrap 5 untuk tampilan responsif
  • Chart.js untuk visualisasi data
  • JavaScript dan jQuery untuk interaktivitas
  • AJAX untuk pengalaman pengguna yang lebih baik
  • PWA (Progressive Web App) untuk akses offline
